[转]使用AutoHotkey在Win下反转鼠标滚轮方向

2012年4月1日 · 1 分钟 · zgia

来自： http://www.swingworks.net/2011/07/reverse_scrolling_with_autohotkey/

让Windows下的鼠标滚轮方向同Lion的自然滚动一样。到http://www.autohotkey.com/download/下载AutoHotkey（选择AutoHotkey_L版本，安装时可以选择32位还是64位），安装，运行。

新建一个空文件，输入内容：

WheelUp::
Send {WheelDown}
Return

WheelDown::
Send {WheelUp}
Return

然后另存为filename.ahk文件，再编译成exe，将此exe设置为自启动即可。
