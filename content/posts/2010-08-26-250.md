Build程序时，出现一个warning: building with 'Targeted Device Family' set to iPhone only ('1') not supported with SDK 'Device - iPhone OS 3.2'。
警告中的“1”，表示程序是iPhone/iTouch的程序。
最后解决方法是：编辑项目设置，
1、将“Base SDK”设置为：“iPhone SDK 4.0”
2、将“iPhone OS Deployment Target”设置为“iOS 3.1.3”
可以查看此文章：[iPhone SDK Release Notes for iOS 3.2](http://developer.apple.com/iphone/library/releasenotes/General/RN-iPhoneSDK-3_2/index.html)
